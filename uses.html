Start with a task, not a brand

What can these AI tools help you do?

Use these examples to choose a tool and write a clearer first question. You still decide what to trust and what to use in your own work.

01 / WRITING

Turn a rough idea into a draft.

Ask for an outline, a clearer explanation, or a different tone. Rewrite the result in your own voice.

Try a starter question

“I have three ideas for a class presentation. Help me turn them into a short outline, and tell me what is still unclear.”

See writing tools →
02 / RESEARCH

Make a long reading manageable.

Summarize your own notes or a document, ask for key terms, then return to the original source to verify details.

Try a starter question

“Summarize the main argument in these notes. List three questions I should check in the original article.”

See research tools →
03 / CODING

Understand an error before changing code.

Describe what you expected, what happened, and the error message. Ask for the reasoning, then test one change at a time.

Try a starter question

“This JavaScript button does nothing when clicked. Explain two likely causes and show me how to test each one.”

See coding tools →
04 / CREATIVE

Explore a visual idea.

Describe the audience, mood, and purpose of your idea. Compare suggestions, then choose and refine your own direction.

Try a starter question

“Suggest three poster concepts for a student event. Keep the design simple and explain the color choices.”

Good habits

Use AI as a helper, not an answer key.

Check facts. Names, dates, quotations and citations may be wrong. Confirm them in a trustworthy source.

Protect privacy. Read a provider's terms before uploading personal information or someone else's work.

Own the result. Follow your course rules and be ready to explain every sentence and every line of code you submit.
